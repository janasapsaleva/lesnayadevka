# Сайт-визитка «Lesnayadevka»

Одностраничный сайт свечной лавки Lesnayadevka: свечи ручной работы из натурального пчелиного воска с пасеки белорусского леса. Стиль: зелёный лес и древесная кора. Заказ принимается в Telegram.

**Основное сообщение:** дух леса, свечи из настоящего пчелиного воска, сделанные руками.

Сайт собирается в Claude Code по правилам из `CLAUDE.md`. Данные магазина (каталог, цены, акции, условия, контакты) настоящие, поэтому перед публикацией проверьте, что они актуальны.

## Что внутри

- `index.html` — весь сайт в одном файле (HTML + CSS в блоке `<style>` + инлайн-SVG). Никакой сборки и зависимостей.
- `CLAUDE.md` — память проекта для Claude Code: правила вёрстки, дизайн, факты о магазине. Хранится только локально, в репозиторий не выкладывается.
- `README.md` — этот файл.
- `images/` — папка для фото свечей и пасеки. Появится, когда будут готовы фото. Пока сайт работает без них.

## Как посмотреть

Открой `index.html` двойным кликом в браузере.

## Как опубликовать на GitHub Pages

1. Создай репозиторий на github.com и загрузи в него файлы проекта.
2. Открой настройки репозитория → раздел Pages.
3. В источнике выбери ветку `main` и папку корень (root), сохрани.
4. Через минуту-две страница будет доступна по ссылке `https://<твой-логин>.github.io/<репозиторий>/`.

Подписи в интерфейсе GitHub иногда меняются — ориентируйся на раздел Pages в настройках репозитория.

## Как подключить свой домен Lesnayadevka.com

1. В настройках Pages найди поле Custom domain и впиши `Lesnayadevka.com`.
2. В настройках домена у регистратора добавь записи DNS, которые покажет GitHub.
3. Когда всё заработает, включи пункт Enforce HTTPS.

Домен подключается не сразу: изменения DNS могут обновляться до нескольких часов.

## Как добавить фото позже

1. Положи фото в папку `images/` рядом с `index.html`. Названия лучше латиницей, например `katanaya-svecha.jpg`. Сожми фото, чтобы страница быстро открывалась.
2. Открой проект в Claude Code и напиши, например: «Добавь фото `katanaya-svecha.jpg` в карточку катаных свечей, а `paseka.jpg` в блок о пасеке».
3. Проверь страницу в браузере и загрузи изменения в репозиторий. GitHub Pages обновит сайт сам.

## Как обновить цены, акции и условия

1. Поменяй данные в разделе «Содержание» файла `CLAUDE.md`: это единственный источник фактов для сайта.
2. Открой проект в Claude Code и напиши: «Обнови сайт по данным из `CLAUDE.md`».
3. Проверь страницу и загрузи изменения в репозиторий.

Так цены на сайте, в посте и в ответах ассистента не расходятся, если база знаний обновляется вместе с `CLAUDE.md`.
